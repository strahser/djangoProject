# scripts — автономные скрипты (работают напрямую с ПК, без сервера)

## create_dated_folder — папка по дате для Total Commander

Открывает в **активной панели Total Commander** окно ввода имени новой
папки (как F7) и вписывает в него дату `2026_10_21_`. Без окна консоли.

### Два режима

| Режим | Что делает | Скорость |
|---|---|---|
| **по умолчанию** | открывает окно ввода и вписывает дату — всё. Дальше вы: `Enter` (создать), `Shift+F6` (переименовать) | ~0.2 с |
| `--auto` | сам жмёт Enter, открывает переименование (Shift+F6) и ставит каретку в конец имени — дописывайте суффикс сразу | ~0.5 с |

### Как это работает

Скрипт не «переключает панель» и не шлёт клавиши вслепую — он использует
**внутренние команды Total Commander** (штатный механизм, описанный на
wiki TC: «AutoHotkey: Send a command to Total Commander»):

| Шаг | Что происходит |
|---|---|
| `cm_MkDir` (907) | TC открывает поле ввода имени новой папки — как F7, в АКТИВНОЙ панели |
| `WM_SETTEXT` | в это поле пишется `2026_10_21_` |
| `Enter` | (только в `--auto`) папка создана и выделена |
| `cm_RenameOnly` (1002) | (только в `--auto`) открывается переименование — как Shift+F6; это edit-контрол `TInEdit` прямо в панели |
| `EM_SETSEL` | (только в `--auto`) снимается выделение, каретка в конце имени |

Команды отправляются сообщением `WM_USER+1075` в окно TC (класс
`TTOTAL_CMD`) — фокус окна для этого не нужен. Номера команд сверяются с
локальным `TOTALCMD.INC` (есть тест).

Фиксированных пауз нет: скрипт ждёт конкретных событий (появилось окно
ввода, в фокусе поле `TInEdit`) и опрашивает их каждые 20–60 мс. Если TC
ещё не обновил панель после создания папки, команда переименования
повторяется (она безопасна — имя не меняется).

Почему не `TOTALCMD.EXE /O`: ключ `/O` открывает путь в **другой** панели
TC — из-за этого скрипт «проваливался» не в ту папку.

### Кнопка в панели Total Commander (штатный способ)

1. Правый клик по **панели кнопок** (под файловыми панелями) → **«Изменить…»**
   (Change) → **«Добавить»** (Add).
2. Заполнить:

   | Поле | Значение |
   |---|---|
   | Команда | `"D:\\Автоматизация\\djangoProject\\.venv\\Scripts\\pythonw.exe"` |
   | Параметры | `"D:\\Автоматизация\\djangoProject\\scripts\\create_dated_folder.py" --no-pause` |
   | Рабочая папка | `D:\\Автоматизация\\djangoProject\\scripts` |
   | Иконка | любая (например, из `wcmicons.dll`) |
   | Подсказка | `Создать папку по дате` |

3. OK → сохранить панель.

`pythonw.exe` — запуск без окна консоли (и без перехвата фокуса: консоль
забрала бы фокус у TC, и переименование не открылось бы).
Путь `%P` не нужен — скрипт сам узнаёт активную панель у TC.

Чтобы кнопка делала всё сразу (создать + переименование), добавьте в
параметры `--auto`.

### Запуск из консоли

```
.venv\Scripts\python.exe scripts\create_dated_folder.py
.venv\Scripts\python.exe scripts\create_dated_folder.py --auto
.venv\Scripts\python.exe scripts\create_dated_folder.py --auto --suffix "КП"
.venv\Scripts\python.exe scripts\create_dated_folder.py --name "2026_10_21_КП"
```

Если Total Commander не запущен — скрипт создаст папку напрямую в
`--base` (по умолчанию — корень проекта) и напишет об этом в лог.

`create_dated_folder.bat` — запуск двойным кликом (тоже без окна консоли).

### Лог

Всё, что происходит, пишется в `scripts/last_run.log` (при запуске через
pythonw консоли нет — смотреть там).

### Где искать Total Commander

Ваш путь `C:\\Program Files\\totalcmd\\TOTALCMD.EXE` прописан первым в списке.
Если установка другая — задайте переменную окружения `TOTALCMD` или
поправьте `TOTALCMD_PATHS` в начале скрипта.
